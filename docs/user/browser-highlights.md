# Browser highlights

Agents can explain a page in T4's integrated browser with numbered callouts. Each callout outlines
one element, adds a matching number badge, and may include a short title and explanation. Callouts
support several colors and can appear together in one viewport.

The agent can scroll a selected callout into view and capture a screenshot containing the visible
callouts. It can replace the current set while an explanation evolves, then clear that exact set.

Highlights are presentation only. They do not edit the website, move its content, or intercept
clicks. They are hidden from accessibility tools. Navigation and reload discard them automatically;
they are never restored or written into the target app.

Highlighting requires an automation-capable desktop browser preview. Other clients can still use
the ordinary browser surface but do not host these tools.
